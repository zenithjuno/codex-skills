# Math figure style

## Scope and status

ใช้เมื่อสร้างหรือปรับขนาดภาพประกอบคณิตศาสตร์ที่ครูขอแล้ว ทั้งภาพแยกและภาพสำหรับ Word อ่านส่วนนี้เมื่อทำภาพเท่านั้น

ส่วนที่นำกลับมาใช้ได้คือการรักษาขนาดจริงบนกระดาษ ตัวช่วยแปลงหน่วย และตัวอย่างกราฟพิกัดหกชนิดที่ทดสอบแล้ว ยังไม่ใช่ตัวสร้างภาพคณิตศาสตร์ทุกชนิดอัตโนมัติ แผนภาพเซตกับเส้นจำนวนใช้ workflow และ preference เดิมของตนเอง

## Shared principles

- เลือกขนาดภาพปลายทางเป็นซม. ก่อนสร้าง กำหนดตัวอักษรและเส้นเป็น pt บนกระดาษ เมื่อเปลี่ยนขนาดภาพให้คำนวณหน่วยวาดใหม่ ไม่ย่อรูปเดิมแล้วปล่อยให้ตัวอักษรเล็กตาม
- เก็บ PNG และ SVG จากพิกัดเดียวกัน พร้อมข้อมูลหรือตัวสร้างสำหรับแก้ไข PNG อย่างน้อย 600 dpi ตามขนาดใช้งานจริง
- แยกภาพข้อละไฟล์ เลขข้อ คำสั่ง และช่องตอบเป็นข้อความ Word นอกภาพ ภาพรวมหลายข้อใช้ตรวจงานเท่านั้น
- ขนาดกราฟกับพื้นที่ทำงานภายในเป็นคนละเรื่อง ห้าม crop พื้นที่ที่เด็กต้องใช้ทำงานเพื่อให้ตัวเลขใหญ่ขึ้น
- ตรวจขอบภาพ ป้ายชนกัน จุดโปร่ง–ทึบ และเส้นที่ถูกป้ายบัง ใช้ภาพเปรียบเทียบด้วยสัดส่วนซม. เดียวกัน การตรวจความอ่านง่ายไม่ได้แทนการตรวจความถูกต้องทางคณิตศาสตร์
- รูปที่มีตัวเลขหรือชื่อแกนไม่ได้เป็นเหตุให้ย้ายสมการโจทย์หรือข้อความคณิตศาสตร์ธรรมดาจาก OMML ไปไว้ในภาพ

## Coordinate-graph profile

โปรไฟล์ส่วนตัวที่ครูรับเมื่อ 2026-10-17: assets/math-figures/coordinate-graph-style.json ตัวเลขเป็นค่าบนกระดาษทุกขนาดภาพ

| ส่วน | ขนาด |
|---|---|
| ตัวเลขและป้ายทั่วไป | 10 pt |
| ชื่อแกนและชื่อกราฟ | 12 pt |
| เส้นกราฟ | 1 pt |
| เส้นแกน | 0.75 pt |
| ขีดแกน / เส้นช่วยอ่าน | 0.5 pt |
| grid เมื่อโจทย์ต้องใช้ | 0.25 pt |
| จุดปลาย | เส้นผ่านศูนย์กลาง 5 pt ขอบหนา 0.75 pt |

ขนาดภาพ 5 ซม. เป็นทางเลือกเฉพาะหน้าชีท Solve ที่ใช้ทดสอบ ไม่ใช่ขนาดบังคับของทุกภาพ เช่นเดียวกับการไม่มีกริดเป็นข้อกำหนดของชุดนั้น ไม่ใช่ข้อห้ามใช้กริด โปรไฟล์กราฟพิกัดไม่ทับฟอนต์ 12/16 pt ที่ครูเคยรับสำหรับแผนภาพเซตและ Word object conversion

คำสั่งล่าสุดของครูและ preference เฉพาะงานมาก่อนค่าเริ่มต้นนี้ การเปลี่ยนค่ากลางต้องมีหลักฐานใหม่ ไม่แก้ตัวเลขเฉพาะกิจแยกในตัวสร้างหลายตัว

## Helper and example

scripts/math_figure_style.py มี PrintStyle.load(height_cm, view_height=760, path=…) และ token(name) เพื่ออ่านค่า pt แล้วแปลงเป็นหน่วยวาด ใช้ raster_scale เลือกจำนวนพิกเซลตามขนาดจริง รองรับ viewBox สูงต่างกัน ไม่ผูกกับขนาดพิกเซลตัวอย่าง

ตัวอย่างใช้งานอยู่ที่ assets/math-figures/examples/function-checking/build_figures.py พร้อม config และ PNG/SVG ตัวแทนกราฟ 1 กับ 6 ตัวอย่างสร้างได้ครบหกรูปโดยไม่ต้องอ่านโปรเจกต์ Solve:

~~~sh
python3 assets/math-figures/examples/function-checking/build_figures.py --size-cm 4 --output-dir /tmp/math-graphs-4cm
~~~

ส่งออกขนาดทดลองไปโฟลเดอร์แยกเสมอ ไม่เขียนทับ asset ภายใน skill ตัวอย่างใช้ Pillow และฟอนต์ Georgia บน macOS ถ้าสภาพแวดล้อมอื่นไม่มีฟอนต์นี้ให้เลือกฟอนต์ที่ตรวจแล้วและตรวจภาพใหม่ ไม่ถือว่าทดสอบข้ามระบบแล้ว

ตัวอย่างตรวจ glyph bounding boxes ป้ายชนกัน และขอบภาพ พร้อมเลื่อนป้ายที่เลยขอบโดยไม่ลดฟอนต์ ถ้าขนาดเล็กจนไม่พอให้แจ้งว่าต้องแก้การวางป้ายหรือลดจำนวนเลขที่ไม่จำเป็น ห้ามทำให้ตัวอักษรเล็กลงเงียบ ๆ ตัวตรวจนี้ยังไม่ตรวจเส้นโค้งชนป้ายหรือความหมายของรูป

## DOCX integration

ให้ภาพและ DOCX อ่านขนาดจาก config เดียวกัน ก่อนผลิตตรวจ manifest ว่าขนาดและโปรไฟล์ตรงกัน หลังบันทึกใช้ verify_docx_media(docx_path, image_paths, height_cm) ตรวจความสูง ลำดับ และ hash ของภาพฝัง แล้วรัน produce.py ตาม workflow ปกติ ตัวช่วยนี้ไม่แทน unified QA หรือ media contract

เมื่อใช้สี่เหลี่ยมจัตุรัส ความกว้างเท่าความสูงได้ สำหรับภาพสัดส่วนอื่นต้องรักษาสัดส่วนและคำนวณทั้งสองมิติเอง ไม่เปลี่ยนสเกลพิกัดทางคณิตศาสตร์เพื่อบังคับภาพให้ลงหน้า

การคงฟอนต์และเส้นไม่ได้รับประกันว่าภาพทุกขนาดลงหน้าเดิมได้ ต้องเรนเดอร์ใหม่หลังเปลี่ยนขนาด และใช้ Word บนเครื่องครูตรวจตำแหน่งภาพขั้นสุดท้าย

## Verification and evidence

~~~sh
python3 tests/test_math_figure_style.py
~~~

ทดสอบส่งออกหกกราฟที่ 4, 5, 6.5 ซม. รวม 18 ภาพ ตรวจฟอนต์ 10/12 pt และเส้นกราฟ 1 pt จาก SVG ที่ส่งออกจริง จุดปลายและพิกัดเส้นตรงกันทุกขนาด PNG อย่างน้อย 600 dpi และกรณีขนาดไม่ถูกต้อง/เล็กเกินไป/ส่งออกทับชุดใช้งาน/ขนาดและ hash ใน Word ผิด

ดู assets/math-figures/size-proof.png กับ size-proof.json เพื่อเทียบขนาดจริง หลักฐานคำสั่งครูอยู่ใน references/evidence-snapshots/math-figure-style-20261017.md และรายการ PREF-20261017-019 ใน preference-evidence.md

## Extension boundary

ใช้ชุดนี้เป็นฐานสะสม preference และตัวอย่างที่พิสูจน์แล้ว การเพิ่มภาพชนิดใหม่ให้ระบุโปรไฟล์ ขอบเขตที่ตรวจ และข้อจำกัดของตัวสร้าง ไม่ย้ายระบบแผนภาพเซต เส้นจำนวน หรือเอกสารเก่าทั้งหมดเพื่อทำให้โครงสร้างเหมือนกัน หากภายหลังเกิดความสามารถใช้ภาพนอก Word มากพอ จึงค่อยพิจารณาแยก skill รวมภาพคณิตศาสตร์
