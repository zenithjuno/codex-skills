# Active DOCX Preference Cards

Open only the card your task needs. These cards are the concise current rules;
[`../preference-evidence.md`](../preference-evidence.md) is background evidence,
not mandatory reading.

- `typography-and-editability.md` — every Thai mathematics DOCX
- `page-layout.md` — page, table, columns, response areas
- `math-notation.md` — mathematical notation and set-builder spacing
- `diagrams-and-visuals.md` — SVG, Venn/Euler, and answer diagrams
- `validation-and-handoff.md` — QA evidence and Word handoff boundary

If the project folder has `DOCX-PREFERENCES.md`, read it first. It may pin or
override these global cards for that project.
