## Authority

For DOCX production: a current teacher instruction wins; then an explicit
topic-specific requirement; then the project's `DOCX-PREFERENCES.md`; then the
relevant global preference card; then a skill default. Old generated DOCX files
are evidence only, never a compatibility target.

The active cards are concise operational rules. The evidence file preserves why
each rule was accepted; it is not routine context.
