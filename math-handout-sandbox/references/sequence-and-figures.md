# Sequence, distilled examples and instructional figures

Use while rebuilding an example progression or when illustrations carry the
explanation. Apply within existing source observations, progression map and
Layout notes; do not create a second tracking system.

## Distilled examples — โจทย์กลั่นแนว

Identify the decision the learner needs to make, prerequisite algebra, and the
necessary condition that makes the decision valid. Simplify arithmetic or
incidental context while keeping that condition. State what remains and what
was reduced; add columns to the existing map only when useful. The next example
should add a meaningful decision, representation or contrast, not just numbers.

“Simple first” is not absolute: a teacher may intentionally use ordered pairs to
rehearse factorization or simultaneous equations. Preserve that chosen purpose.
When teaching a property, consider a nearby case missing its key condition and a
counterexample, e.g. cancelling a Cartesian-product factor requires it nonempty.
Use contrasts where they earn their teaching time; do not add one mechanically
for every formula. For transformations, one-axis movement can precede both axes.

Keep summaries compact: usable rule plus decisive caution. Put detailed reasoning
in named examples and explicitly locate the example teaching each caution.
Never weaken a domain restriction, lose a forbidden input after cancellation, or
silently assume a quadratic's leading coefficient is 1 to shorten the question.

Label authored items as distilled examples, not actual exam questions. Exam
frequency or provenance needs evidence. For a real-world rate, cite the original
source/date and state the simplification; current rates need fresh verification.

## Preserve intended coverage

When replacing or moving content, use the existing source/transfer table to point
to its destination, or record the teacher-approved cut. A simpler substitute is
not proof that the original skill survived. A deferred item stays deferred until
explicitly used or cut; do not add parked work back to an accepted sheet.

If “leave one problem” could mean one word problem or one example of every kind,
state the interpreted affected set briefly before a broad edit. Ask only if the
scope remains consequentially ambiguous; do not ask again when the session
already resolves it. At chapter acceptance, update its index without marking
unperformed audits passed or closing an entire multi-chapter course.

## Figures need an explanatory job

For each concept figure identify: what to notice, required labels/operations,
meaning of each line, and the brief sentence linking it to the next decision.
A picture's presence and media hash do not establish those four things.

Examples: vertex discussion needs a vertex label; inverse reflection needs why
keeping one branch makes the inverse a function; composition needs order arrows
and the total mapping. A parent-graph bundle should support the following
transformation examples. Keep the explanation brief and in the teacher's accepted
voice. Reuse accepted wording to avoid repeatedly drifting back to formal prose.

Read the project DOCX profile and route approved production to thai-math-docx;
its teaching-page-layout reference contains the layout assemblies. Do not design
an unasked visual or begin production merely because a figure would be possible.
